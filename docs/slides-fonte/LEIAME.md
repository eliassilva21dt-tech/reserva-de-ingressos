# Fonte dos slides

Cópia de segurança do deck publicado no claude.ai (artefato "Reserva de Ingressos — Apresentação").
`deck.json` é o índice e `slides/*.html` são os slides, um por arquivo. Estes arquivos só abrem como
apresentação dentro do artefato; para apresentar, baixe o `.pptx` ou o PDF pelo menu da página do deck.
